# PGYMacMenu 软件使用说明

## 1. 安装与启动

构建应用：

```bash
./scripts/build_app.sh
```

构建完成后应用位于：

```text
dist/PGYMacMenu.app
```

双击 `PGYMacMenu.app` 启动后，应用不会出现在 Dock。启动时会显示 `PGYMacMenu 已启动` 窗口；菜单栏图标默认关闭，开启后台运行后可按需显示。默认配置下，关闭最后一个窗口会直接退出应用。

## 2. 初次配置

从启动窗口依次打开以下配置；开启后台运行和菜单栏图标后，也可从菜单栏进入：

1. `API Key 配置...`
   - 新建配置
   - 填写名称
   - 填写蒲公英 API Key
   - 可选填写安装密码
   - 可选填写该 API Key 默认更新说明
   - 点击保存

2. `更新模板配置...`
   - 新建常用更新说明模板
   - 填写模板名称和模板内容
   - 点击保存

3. `偏好设置...`
   - 可选配置 `aapt` 工具路径
   - 可选配置 Android SDK 目录
   - 可选开启“允许关闭窗口后继续运行”
   - 可选开启“显示菜单栏 PGY 图标”
   - 可选开启“上传成功后自动退出应用”

菜单栏图标默认关闭；只有开启“允许关闭窗口后继续运行”后，才允许开启菜单栏 `PGY` 图标。关闭后台运行时，菜单栏图标会被强制关闭。

`aapt` 工具通常位于：

```text
~/Library/Android/sdk/build-tools/<version>/aapt
```

如果未配置，应用会自动从 Android SDK 默认目录和环境变量中查找。

## 3. 配置 WebDAV 加密同步

同步是可选功能。配置后，应用会在当前 Mac 和 WebDAV 远端文件之间进行安全的双向合并。

### 3.1 准备连接信息

进入 `偏好设置...`，切换到 `同步` 标签页，填写：

1. `WebDAV 根 URL`：必须是 `https://` 地址
2. `远端文件路径`：相对于根 URL 的路径，默认为 `PGYMacMenu.sync`
3. `用户名` 和 `WebDAV 密码`：建议使用服务商提供的应用专用密码
4. `同步口令`：至少 12 个字符
5. 再次输入完全相同的同步口令

同步口令不会自动裁剪首尾空格。请妥善保管；它用于加密远端文件，应用和 WebDAV 服务商均无法找回。

坚果云配置：

- `WebDAV 根 URL`：`https://dav.jianguoyun.com/dav/`
- `用户名`：坚果云注册邮箱
- `WebDAV 密码`：在坚果云“第三方应用管理”中生成的应用密码，不是账号登录密码
- `远端文件路径`：`PGYMacMenu.sync`

根 URL 必须指向已经存在的 WebDAV 根目录。不要把同步文件名或尚未创建的子目录拼进根 URL；需要使用子目录时，应将它写在远端文件路径中。坚果云兼容性不以单一条件创建为前提，应用会探测可用的安全写入机制，最终以应用内的 `测试连接` 结果为准。参见[坚果云官方 WebDAV 配置说明](https://help.jianguoyun.com/?p=2064)。

### 3.2 测试并保存

点击 `测试连接`。应用会使用临时远端文件验证：

- HTTPS 连接和登录信息有效
- 目录可创建且文件可读写、删除
- 服务端至少有一种通过安全探测的写入机制：强 ETag 条件写入、严格验证的 exclusive `LOCK`，或不可变快照使用的条件创建/同目录非覆盖 `MOVE`

测试通过后点击 `保存设置`。保存操作只会把连接信息写入当前 Mac 的 Keychain，不会再次连接 WebDAV，也不会上传或恢复配置。应用优先使用强 ETag 和 `If-Match`；否则使用严格验证的标准 WebDAV exclusive `LOCK`/`UNLOCK`；两者都不可用时，在远端文件同级的 `<文件名>.d/` 目录使用不可变加密快照。该目录包含一个 `genesis.pgy` 和按密文哈希命名的对象。对象优先通过可靠的 `If-None-Match: *` 条件创建；条件创建不安全时，应用先写入随机临时对象，再用已验证的同目录 `MOVE` 和 `Overwrite: F` 发布。目标已存在时移动必须失败且不改写文件，应用不允许无条件覆盖已有对象；所有安全机制均未通过时才拒绝同步。

`测试连接` 不读取或修改既有远端配置和快照。如果远端文件路径包含尚不存在的父目录，会先创建这些目录；之后只创建、读取、冲突写入并删除不含应用配置和同步口令的临时探针。

### 3.3 日常同步

- 点击 `立即同步` 才会执行一次拉取、逐记录合并和安全上传
- 保存或删除本地配置只会将状态标记为“待手动同步”，不会产生网络请求
- 应用启动、重新激活和退出时均不会检查或写入 WebDAV
- 退出时未上传的修改会继续保存在本机，下次打开后仍需手动点击 `立即同步`

状态区会显示未配置、待手动同步、同步中、最后成功时间或脱敏后的错误信息。只有 `立即同步` 会拉取或上传真实配置数据。

点击 `移除配置` 会停止同步并删除当前 Mac 上的 WebDAV 凭据和同步口令，但不会删除远端备份文件。

### 3.4 同步范围

会同步：

- API Key 配置的名称、API Key、安装密码和默认更新说明
- 更新说明模板
- 允许后台运行、显示菜单栏图标、上传成功后自动退出这三项行为偏好

不会同步：

- `aapt` 可执行文件路径
- Android SDK 目录

工具路径只适用于当前 Mac。同步远端偏好时，应用会保留本机已有的工具路径。

## 4. 从菜单栏上传 APK

1. 点击菜单栏图标
2. 选择 `上传 APK...`
3. 选择 `.apk` 文件
4. 确认 APK 信息
5. 选择 API Key 配置
6. 输入更新说明，或选择更新模板
7. 点击上传
8. 等待上传与发布完成
9. 查看短链、二维码和蒲公英返回信息

## 5. 从 Finder 右键上传 APK

1. 先启动一次 `PGYMacMenu.app`
2. 在 Finder 中选中 `.apk` 文件
3. 右键打开服务或快速操作菜单，选择 `上传到蒲公英`
4. 后续流程与菜单栏上传一致

如果服务菜单暂未出现，可尝试：

```bash
/System/Library/CoreServices/pbs -flush
```

然后重新启动应用或重新登录 macOS。

## 6. 配置存储与恢复

- API Key、安装密码、WebDAV 凭据和同步口令保存在系统 Keychain
- 本地配置通过版本化 manifest 和分代 Keychain 密钥包原子保存
- 远端文件只包含 AES-256-GCM 加密后的内容；密钥由独立同步口令使用 PBKDF2-HMAC-SHA256 600,000 次派生
- 不可变快照会合并多设备分支后追加新对象，并通过本机锚点检测已观察历史的回放；对象上限为 512 个，单次下载上限为 64 MiB
- 应用不会在控制台输出 API Key、安装密码、WebDAV 密码或同步口令

恢复边界：

- 同一台 Mac 卸载重装后，只要对应 Keychain 项仍存在，应用可恢复同步连接；点击 `立即同步` 后拉取配置
- 换新 Mac 或清空 Keychain 后，需要重新填写 WebDAV 信息和原同步口令，再执行同步恢复
- 忘记同步口令后无法解密远端备份；版本 1 不提供口令找回或静默重置
- 已使用过该数据集的 Mac 会记录锚点：单文件模式可检测数据集替换、同代篡改、版本降低和相邻代前驱异常；不可变模式还能检测已观察的仓库对象被替换或隐藏。全新设备无法证明服务端是否回放了旧的合法密文
- 首次切换到不可变快照前，请先升级所有设备；迁移后不要再使用只写单文件的旧构建，否则旧构建产生的变更不会进入不可变仓库

## 7. 常见问题

### APK 元信息显示“未识别”

通常是未找到 `aapt`。请在 `偏好设置...` 中配置 `aapt` 可执行文件路径，或配置 Android SDK 目录。

### 上传前提示未配置 API Key

进入 `API Key 配置...` 新建至少一个配置，并填写 API Key。

### Finder 右键入口不可见

先启动一次应用，让 macOS 注册服务；必要时执行：

```bash
/System/Library/CoreServices/pbs -flush
```

然后重新打开 Finder 右键菜单。

### 关闭窗口后应用仍在运行

检查 `偏好设置...` 中是否开启了“允许关闭窗口后继续运行”。默认关闭该选项，关闭最后一个窗口会退出应用。

### 测试连接提示“不支持安全并发同步”

仅当 WebDAV 服务未通过强 ETag 条件写入、exclusive `LOCK`、可靠的 `If-None-Match: *` 条件创建和同目录 `MOVE`（`Overwrite: F`）非覆盖语义的安全测试时，才会提示此错误。请检查服务或反向代理配置，或更换兼容服务；应用不允许无条件覆盖已有对象。坚果云是否兼容以应用内测试结果为准。

### 同步提示口令错误或远端文件损坏

确认输入的是创建该远端文件时使用的同步口令。应用检测到认证失败、文件损坏或未知格式时会停止写入，避免覆盖仍可恢复的数据。

### 远端文件突然不存在

如果当前 Mac 以前已经观察到该远端数据集，应用不会把突然出现的 `404` 当作首次同步并自动重建。请先在 WebDAV 服务中恢复文件；如果确实要建立新数据集，请改用一个新的远端文件路径。移除同步配置不会删除这项回放保护记录。

### 重装后没有恢复配置

应用不会在启动时自动访问 WebDAV。请先打开同步设置确认连接信息仍在，再点击 `立即同步`。若系统 Keychain 已被清理，需要重新输入 WebDAV 根 URL、路径、账号和原同步口令；远端备份不会包含可用于解密自身的口令。
